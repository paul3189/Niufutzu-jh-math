🧭拆解問題的四個提問

① 這題「問什麼」？

  • 求一個數 → 列方程式
  • 求範圍 → 列不等式
  • 求長度 → 畢氏定理、相似形
  • 求角度 → 內角和、外角、平行線截角
  • 求面積體積 → 找底與高
  • 要證明 → 三角形全等

② 題目「給了什麼」？

  • 給兩條平行線 → 同位角、內錯角、同側內角
  • 給直角 → 畢氏定理
  • 給兩組角相等 → AA 相似
  • 給中點 → 中點連線定理
  • 給圓與角 → 圓周角定理
  • 給一堆數據 → 平均數、中位數、盒狀圖

③ 我有「哪些工具」？

  • 算不出來時，先把圖畫出來並標上已知
  • 幾何找不到路 → 找直角三角形或相似三角形
  • 正面難算 → 用餘事件（至少 → 1 減）
  • 數字太醜 → 先因式分解或設未知數
  • 看不出規律 → 列出前幾項再看差

④ 這個工具的「限制」是什麼？

  • 不等式乘除負數 → 變號
  • 根號內 ≥ 0、分母 ≠ 0
  • 平方後 → 兩個答案，要檢查合不合理
  • 全等判別沒有 SSA、AAA
  • 圓周角定理要對同一段弧
  • 相似的面積比是 k² 不是 k

💡怎麼用這張圖

平常讀書時：每讀完一章，回到這張圖找到它的位置，問自己「它跟旁邊的主題有什麼關係？」—— 孤立記住的公式最容易忘，長在樹上的公式才叫理解。

寫題目卡住時：不要馬上翻解答。先問「這題屬於哪個領域？」→ 進入該分支圖 → 掃過那個主題的所有工具 → 逐一問「這個工具的觸發條件，題目有沒有給？」

幾何題卡住時：去幾何圖解牆把圖掃一遍。 很多時候不是不會，而是「沒想到這張圖可以這樣用」。

訂正錯題時：錯的往往不是計算，而是「限制沒檢查」。到工具的限制／前提欄 找到你踩的那個坑，把它抄進錯題本。

考前複習時：切到自己的年級，把每個領域的分支圖印出來，遮住「工具」欄，只看「什麼時候用」， 測試自己能不能反射性地說出工具名稱。

牛夫子說： 一直重讀課本很容易讀到睡著。改成「看著這張圖，把每個主題的工具唸出來」—— 唸得出來的跳過，卡住的才回去讀，時間會省一半。
