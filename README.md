# 國中數學工具地圖

「高中數學教學系統」裡那張知識體系心智圖的**國中版**。同一套骨架（心智圖 → 分支圖 → 工具抽屜 →
關鍵字搜尋），但幾何的部分改成**以圖為主**。

雙擊 `index.html` 就能開，不需要安裝任何東西、也不需要網路。

## 內容規模

| 項目 | 數量 |
|---|---|
| 領域 | 10 |
| 主題 | 38 |
| 工具 | 195（其中 9 項掛「補充」標籤） |
| 幾何 SVG | 105 張 |

五個幾何領域（線角與三角形、四邊形與多邊形、圓、畢氏與相似、立體圖形）
共 112 項工具，**每一項都配一張圖**；坐標與函數另有 5 張函數圖形。
（這些數字用 `node _audit/check_data.js` 重算，不要手改。）

除了定理本身，「**解題時實際會畫的那條線**」也各自成卡：
相似形收了四種常見型態（A 字型、X 字型、共角型、母子型）——題目裡的相似三角形
幾乎都是這四種疊在一起的樣子，認出型態就知道對應順序怎麼寫；
梯形收了兩種標準輔助線（作兩條高切成矩形＋兩個直角三角形、作平行於一腰的線切成平行四邊形＋三角形）。

年級以 **108 課綱學習內容的編碼**為準（例：D-7-2 就是七年級），章節編排參考 113 年版課本
（對照表：amathing.world/108-math-contents）。幾個容易標錯的位置：
平均數、中位數、眾數是**七年級**（D-7-2），全距、四分位距、盒狀圖是**九年級**（D-9-1），
相對次數與累積次數是八年級（D-8-1）；角的關係（互餘、互補、對頂角）是八年級（S-8-1）；
兩點距離公式是八年級（G-8-1）；多項式的乘法是八年級（A-8-3）；重心、外心、內心是九年級（S-9-8～10）；
連比、三角形兩邊中點連線在九年級（梯形兩腰中點連線則是八年級）；生活中的幾何（垂直、線對稱、三視圖）在七年級；立體圖形全在九年級。
一個主題橫跨兩個年級時（`g: [7, 9]`），**每一張工具卡要自己再標 `g`**，
否則切年級時它會在兩個年級都出現。

**範圍以 108 課綱國中為準**，而且是逐條對過官方領綱的「學習內容」條文（2026-09 全面盤點）：
尤拉公式、立體截面、球的體積與表面積不在國中，工具地圖與道場題庫都沒有收。
**歪斜線在國中**（S-9-12「空間中的線與平面」明列線與線的平行、垂直與歪斜），
之前誤刪，現在放在「立體圖形與測量 ▸ 空間中的線與平面」。

### 「補充」標籤：超綱內容保留、但要標出來

有些內容課綱沒有、但老師上課常會帶到。這些**不刪**，改成在工具上加一個 `ext` 欄位，
寫明課綱依據；畫面上凡是出現這張卡的地方（心智圖葉節點、圖卡、總表、搜尋結果、抽屜）都會掛
「補充」標籤，抽屜最下面會多一段「課綱範圍」說明。目前有 9 項：

| 補充內容 | 課綱依據 |
|---|---|
| 錐體體積 ⅓ | S-9-13 只有「直角柱的體積」；錐體只到展開圖與表面積 |
| 兩圓的位置關係 | S-9-7 只有點與圓、直線與圓 |
| 由一般式配方求頂點、拋物線與 x 軸的交點 | F-9-2 備註：二次函數的配方法與應用問題是 10 年級 |
| 聯立方程式的無解／無限多解、兩直線的平行與重合 | A-7-6 只處理恰有一個交點的情形；國中沒有斜率 |
| 連續動作的機率相乘、不放回 | D-9-2 樹狀圖限兩層、對稱情形 |
| 三項和的平方 | A-8-1 只列四條乘法公式 |
| 中點坐標 | G-8-1 只列兩點距離公式 |

道場的題目也一樣：題庫裡超綱的題（錐體體積、兩圓、相似立體體積比、科學記號相乘、
用 $a^2+b^2$ 與 $c^2$ 的大小判斷銳角鈍角…）都標了 `ext`，**預設不出**，
在選單勾「包含補充題」才會出，題目上會顯示「補充」。

兩個容易放錯的位置（已向授課老師確認課本編排）：**多邊形外角和**是八年級的正式內容
（課綱 S-8-2 的備註雖然寫「不處理外角和公式」，課本在多邊形的內角與外角就會教）；
**梯形兩腰中點連線**在八年級最後一章「各類四邊形」的梯形小節（課綱 S-8-11），
不要跟九年級相似形的「三角形兩邊中點連線」（S-9-3）放在一起。
兩項其實是國中範圍、只是原本歸錯單元的，改成重新歸類而不是刪掉：

- **體對角線 / 正方體對角線** → 移到「畢氏定理」（國中在這一章教）
- **n 角柱的面數** → 移到「柱體」

`_figs/custom_figs.py` 裡 `sol_sphere`、`sol_cube_section` 兩個函式保留但停用，
需要時把它們加回檔尾的清單即可。

圖與敘述必須一一對應：例如「弓形面積」不能只畫扇形，要畫「扇形 − 三角形 ＝ 弓形」；
「直線與圓的位置關係」要畫齊相離／相切／相交三種；「切線長相等」要真的畫出圓外一點的兩條切線。
寬型的多格圖（viewBox 寬 ≥ 400 且長寬比 ≥ 1.5）在圖卡格線裡會自動橫跨兩欄，避免縮到看不清。

## 幾何圖形一律「先定義、再性質」

每個幾何圖形的條目都拆成三段，各自獨立成卡：

1. **定義**（資料的 `d` 欄）——它「是什麼」，一句話，抽屜裡排在最上面
2. **性質**（`f` 欄，用 `\begin{gathered}` 條列，一條一行）——已知它是這個圖形後能用什麼
3. **判別**（另立卡片）——還不知道、要證明它是這個圖形時能用什麼

例：矩形 → 定義「有一個內角是直角的平行四邊形」；性質三條；判別三條。
目前共 28 個圖形條目有定義（四邊形家族 8 個、三角形相關 8 個、圓 5 個、立體 6 個、正多邊形 1 個）。

判別法（criteria）刻意一條一張圖、一條一張卡：
平行四邊形 5 條、矩形 3 條、菱形 3 條、等腰梯形 2 條、三角形全等 5 條（SSS/SAS/ASA/AAS/RHS）、
三角形相似 3 條（AA/SAS/SSS）、平行線 3 條、兩圓位置 5 種（補充）。

包含關係要前後一致：這份地圖採「正方形 ⊂ 矩形、正方形 ⊂ 菱形、菱形是特殊的箏形」，
所以性質的敘述只能說「**不一定**相等／垂直」，不能說「不相等」。

另外用三張圖專門處理 **SSA 的模稜兩可情形**：為什麼會有兩個三角形、
兩解的兩個角為什麼互補（$\angle 1+\angle 2=180^\circ$）、以及直角時為什麼只有一解（RHS 的由來）。

**直覺道場**（`reflex.html`）練的是地圖練不到的東西：不是「查得到」，而是「不用查也想得到」。

所以可以只練某幾個單元（可複選）或某一個年級，結束後的診斷會直接連回該單元的抽屜。
題庫在 `data/reflex-bank.js`：計算題由產生器即時出（數字每次不同），觀念題手寫。
單元名稱以工具地圖為準（`reflex.html` 會先載入 `data/jm-*.js`，題庫自動對名稱、對不上會在 console 警告）；
年級寫在每一題自己身上，選「七年級」就只會出七年級的題，即使那個單元橫跨兩個年級。

## 改內容

**改文字**：編輯 `data/jm-*.js`，存檔後重新整理瀏覽器。欄位意義見 `data/toolmap.js` 開頭。

**加一張圖**：

```bash
python _figs/render_all.py
```

- 標準圖形 → 在 `_figs/spec.json` 的 `figures` 加一筆（參數見 `jh-math-geometry` 技能的
  `references/figure-catalog.md`）。注意渲染器的 `similar_triangles` 一定會把第二個三角形放大、
  符號固定畫「∼」，**不能拿來畫全等**，邊長數字也不會按比例畫；全等與相似的並排圖請用
  `custom_figs.py` 的 `_cong_pair()`／`_sim_pair()`
- 特殊圖形 → 在 `_figs/custom_figs.py` 寫一個函式，並加進檔尾的清單
- 重建後在工具上加 `fig: "圖的 id"` 即可

## 公式不橫向捲動

公式是每張工具卡最主要的東西，要一眼看完，所以**過長的公式一律拆成多行往下長**，
不用左右捲軸。KaTeX 的 display 公式不會自動換行，換行是寫在資料裡的
`\begin{gathered}…\\…\end{gathered}`。

決定寬度的是手機（抽屜滿版 375px，公式框可用約 327px），比桌機更緊。
新增或修改公式後：

```bash
python _figs/wrap_formulas.py
```

它會在語意分隔處（`;\quad`、邏輯箭頭、逗號、加號、中文標點）自動拆行。
`--dry` 只看會改什麼、`--check` 只列出估算過寬的行。

**估算不是最終依據**——分數會高估、巨集會低估。改完請開瀏覽器實測，
在 console 貼上下面這段，把每一條公式都開一次抽屜量寬度（結果應為空陣列）：

```js
(async()=>{const bad=[];for(const r of MathMap.allTools().filter(r=>r.tool.f)){
  MathMap.openTool(r.tool,'');const b=document.querySelector('#mmDrawer .dw-formula');
  if(!b)continue;const k=b.querySelector('.katex-display');
  const w=k?k.scrollWidth:b.scrollWidth,c=k?k.clientWidth:b.clientWidth;
  if(w>c+1)bad.push([r.tool.n,w,c]);}
  document.getElementById('mmDrawer').classList.remove('open');console.log(bad);})()
```

記得同時用手機寬度（375px）測一次，那才是最窄的情況。

**換配色**：網站色票在 `assets/theme-cow.css` 的 `:root`；
幾何圖的顏色對照表在 `_figs/build_figs.py` 的 `PALETTE`（改完要重跑 `render_all.py`）；
十個領域各自的顏色寫在 `data/jm-*.js` 開頭的 `color`。

**換／加吉祥物圖**：把原圖丟進 `assets/mascot/`（檔名以 `cow_` 開頭），執行：

```bash
python _figs/prep_mascot.py
```

它會從四角 flood fill 去背（牛夫子身體本來就是白的，所以不能整張把白變透明）、
裁掉留白、縮到最長邊 560px，輸出到 `assets/mascot/web/`。

`render_all.py` 會自動找 `jh-math-geometry` 技能的 `geometry_renderer.py`；找不到時可設環境變數
`JH_GEOM_DIR` 指向該技能的 `scripts/` 目錄。它跑完會檢查每張圖的文字有沒有跑到畫布外。

## 改完一定要跑的檢查（`_audit/`）

內容正確性是這份地圖的第一要務，所以檢查都寫成腳本，改完就重跑：

```bash
node _audit/check_data.js
```

重算領域／主題／工具／圖的數量；找出引用了卻不存在的圖、沒被用到的圖、幾何工具沒配圖的；
比對道場題庫的單元 id 與名稱是否都在地圖裡；列出所有「補充」項目。

```bash
node _audit/fuzz_bank.js
```

每種題型各出 2 萬題，檢查：選項是否恰好 4 個且互異、有沒有 NaN／Infinity、正解與誘答的格式是否一致
（例如只有正解沒包 `$…$`）、係數 1 有沒有被寫成 `1x`、畢氏題的「最長邊」是否真的最長且圍得成三角形、
年級範圍內會不會出到別的年級的題、補充題在沒勾選時會不會漏出來。**結尾必須是 `0 個問題`。**

```bash
node _audit/length_cue.js --all
```

列出手寫題裡「正解是四個選項中唯一最長」的題目。四選一沒有長度線索時應該在 25% 上下
（2026-09 從 55% 改到 24%）；新增手寫題後跑一次，太長的正解把括號裡的補充說明搬到「理由」去。

```bash
python _audit/contact_sheet.py
```

把 `_figs/out/*.svg` 每 12 張排成一張總覽圖（輸出到 `_audit/sheets/`），用眼睛逐張對：
圖和敘述有沒有一一對應、標籤有沒有疊在一起、數字和形狀合不合（3-4-5 就要畫成直角）。
需要 `pip install playwright` 與 `playwright install chromium`。

曾經出過的錯（留著當檢查清單）：全等圖用了相似三角形的渲染器，畫成一大一小＋「∼」；
標 3、4、5 的三角形沒畫成直角；一般梯形畫成等腰梯形；題庫出過「3, 4, 7 的三角形」。

## 圖形風格

幾何圖由 `jh-math-geometry` 技能的渲染器產生（serif 字體、`#222` 線條、等邊刻度／角弧／直角符號
的標記系統），與段考卷用圖一致——同一張圖可以直接拿去出題或做講義。
