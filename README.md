# 國中數學工具地圖

「高中數學教學系統」裡那張知識體系心智圖的**國中版**。同一套骨架（心智圖 → 分支圖 → 工具抽屜 →
關鍵字搜尋），但幾何的部分改成**以圖為主**。

雙擊 `index.html` 就能開，不需要安裝任何東西、也不需要網路。

## 內容規模

| 項目 | 數量 |
|---|---|
| 領域 | 10 |
| 主題 | 36 |
| 工具 | 188 |
| 幾何 SVG | 96 張 |

五個幾何領域（線角與三角形、四邊形與多邊形、圓、畢氏與相似、立體圖形）
共 105 項工具，**每一項都配一張圖**；坐標與函數另有 5 張函數圖形。

除了定理本身，「**解題時實際會畫的那條線**」也各自成卡：
相似形收了四種常見型態（A 字型、X 字型、共角型、母子型）——題目裡的相似三角形
幾乎都是這四種疊在一起的樣子，認出型態就知道對應順序怎麼寫；
梯形收了兩種標準輔助線（作兩條高切成矩形＋兩個直角三角形、作平行於一腰的線切成平行四邊形＋三角形）。

章節範圍與年級以 **113 年版（翰林、康軒、南一統一）** 的編排為準
（對照表：amathing.world/108-math-contents）。幾個容易對錯的位置：
連比例、三角形兩邊中點連線、梯形中線在「相似形」（九上）；
四分位數與盒狀圖在九下「資料的分析」；生活中的幾何（垂直、線對稱、三視圖）在七下；
指數律在七上；角的關係（補角餘角對頂角）在八下；立體圖形全在九下。

**範圍以 108 課綱國中為準**：尤拉公式、歪斜線、立體截面、球的體積與表面積都不在國中，
工具地圖與「牛夫子直覺道場」的題庫（`data/reflex-bank.js`）都已一併移除。
兩項其實是國中範圍、只是原本歸錯單元的，改成重新歸類而不是刪掉：

- **體對角線 / 正方體對角線** → 移到「畢氏定理」（國中在這一章教）
- **n 角柱的面數** → 移到「柱體」

`_figs/custom_figs.py` 裡 `sol_sphere`、`sol_cube_section` 兩個函式保留但停用，
需要時把它們加回檔尾的清單即可。

圖與敘述必須一一對應：例如「弓形面積」不能只畫扇形，要畫「扇形 − 三角形 ＝ 弓形」；
「直線與圓的位置關係」要畫齊相離／相切／相交三種；「切線長相等」要真的畫出圓外一點的兩條切線。
寬型的多格圖（viewBox 寬 ≥ 400 且長寬比 ≥ 1.5）在圖卡格線裡會自動橫跨兩欄，避免縮到看不清。

## 幾何圖形一律「先定義、再性質」

每個幾何圖形的條目都拆成三段，各自獨立成卡：

1. **定義**（資料的 `d` 欄）——它「是什麼」，一句話，抽屜裡排在最上面
2. **性質**（`f` 欄，用 `\begin{gathered}` 條列，一條一行）——已知它是這個圖形後能用什麼
3. **判別**（另立卡片）——還不知道、要證明它是這個圖形時能用什麼

例：矩形 → 定義「有一個內角是直角的平行四邊形」；性質三條；判別三條。
目前共 28 個圖形條目有定義（四邊形家族 8 個、三角形相關 8 個、圓 5 個、立體 6 個、正多邊形 1 個）。

判別法（criteria）刻意一條一張圖、一條一張卡：
平行四邊形 5 條、矩形 3 條、菱形 3 條、等腰梯形 2 條、三角形全等 5 條（SSS/SAS/ASA/AAS/RHS）、
三角形相似 3 條（AA/SAS/SSS）、平行線 3 條、兩圓位置 5 種。

另外用三張圖專門處理 **SSA 的模稜兩可情形**：為什麼會有兩個三角形、
兩解的兩個角為什麼互補（$\angle 1+\angle 2=180^\circ$）、以及直角時為什麼只有一解（RHS 的由來）。

右上角可切「全部／七年級／八年級／九年級」，只顯示該年級的主題（設定記在瀏覽器）。

**直覺道場**（`reflex.html`）練的是地圖練不到的東西：不是「查得到」，而是「不用查也想得到」。
一場 10 題（約 2 分鐘），在秒數內按對就打怪、想太久就被怪打；題目掛在工具地圖的單元上，
所以可以只練某幾個單元（可複選）或某一個年級，結束後的診斷會直接連回該單元的抽屜。
題庫在 `data/reflex-bank.js`：計算題由產生器即時出（數字每次不同），觀念題手寫。

## 改內容

**改文字**：編輯 `data/jm-*.js`，存檔後重新整理瀏覽器。欄位意義見 `data/toolmap.js` 開頭。

**加一張圖**：

```bash
python _figs/render_all.py
```

- 標準圖形 → 在 `_figs/spec.json` 的 `figures` 加一筆（參數見 `jh-math-geometry` 技能的
  `references/figure-catalog.md`）
- 特殊圖形 → 在 `_figs/custom_figs.py` 寫一個函式，並加進檔尾的清單
- 重建後在工具上加 `fig: "圖的 id"` 即可

## 公式不橫向捲動

公式是每張工具卡最主要的東西，要一眼看完，所以**過長的公式一律拆成多行往下長**，
不用左右捲軸。KaTeX 的 display 公式不會自動換行，換行是寫在資料裡的
`\begin{gathered}…\\…\end{gathered}`。

決定寬度的是手機（抽屜滿版 375px，公式框可用約 327px），比桌機更緊。
新增或修改公式後：

```bash
python _figs/wrap_formulas.py
```

它會在語意分隔處（`;\quad`、邏輯箭頭、逗號、加號、中文標點）自動拆行。
`--dry` 只看會改什麼、`--check` 只列出估算過寬的行。

**估算不是最終依據**——分數會高估、巨集會低估。改完請開瀏覽器實測，
在 console 貼上下面這段，把每一條公式都開一次抽屜量寬度（結果應為空陣列）：

```js
(async()=>{const bad=[];for(const r of MathMap.allTools().filter(r=>r.tool.f)){
  MathMap.openTool(r.tool,'');const b=document.querySelector('#mmDrawer .dw-formula');
  if(!b)continue;const k=b.querySelector('.katex-display');
  const w=k?k.scrollWidth:b.scrollWidth,c=k?k.clientWidth:b.clientWidth;
  if(w>c+1)bad.push([r.tool.n,w,c]);}
  document.getElementById('mmDrawer').classList.remove('open');console.log(bad);})()
```

記得同時用手機寬度（375px）測一次，那才是最窄的情況。

**換配色**：網站色票在 `assets/theme-cow.css` 的 `:root`；
幾何圖的顏色對照表在 `_figs/build_figs.py` 的 `PALETTE`（改完要重跑 `render_all.py`）；
十個領域各自的顏色寫在 `data/jm-*.js` 開頭的 `color`。

**換／加吉祥物圖**：把原圖丟進 `assets/mascot/`（檔名以 `cow_` 開頭），執行：

```bash
python _figs/prep_mascot.py
```

它會從四角 flood fill 去背（牛夫子身體本來就是白的，所以不能整張把白變透明）、
裁掉留白、縮到最長邊 560px，輸出到 `assets/mascot/web/`。

`render_all.py` 會自動找 `jh-math-geometry` 技能的 `geometry_renderer.py`；找不到時可設環境變數
`JH_GEOM_DIR` 指向該技能的 `scripts/` 目錄。它跑完會檢查每張圖的文字有沒有跑到畫布外。

## 圖形風格

幾何圖由 `jh-math-geometry` 技能的渲染器產生（serif 字體、`#222` 線條、等邊刻度／角弧／直角符號
的標記系統），與段考卷用圖一致——同一張圖可以直接拿去出題或做講義。
